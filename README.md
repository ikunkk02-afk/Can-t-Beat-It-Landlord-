# 打不过就斗地主

Minecraft **1.21.1 · NeoForge 21.1.265+ · Java 21 · GeckoLib 4.9.3**。把 Boss 战变成一局三人斗地主。

## 安装与开局

1. 从 [GitHub Releases](https://github.com/ikunkk02-afk/Can-t-Beat-It-Landlord-/releases/latest) 下载模组 JAR，与 [GeckoLib 4.9.3（NeoForge 1.21.1）](https://modrinth.com/mod/geckolib/version/Grwn5rUB) 一起放入 `mods` 文件夹。联机时服务端和客户端都要更新。
2. 靠近监守者、凋灵或末影龙，在附近找一片约 5×5 格、上方无遮挡的平地，按 **F7**。可在控制设置中改键，也可执行 `/bosslandlord`。
3. 在选角界面选择附近生物、闹吃或古振兴。附近没合适的生物时，默认可补一名临时村民。上方切换选项，下方预览模型，点击「确认入座」或按 Enter 开局。
4. 也可以用 **3 张纸 + 1 个红石粉** 无序合成「生命赌局邀请牌」，靠近 Boss 后手持右键发起。

在单人存档的「模组 → 打不过就斗地主 → 配置」开启「生存模式可挑战任意生物」后，对准生物按 **F7** 或使用邀请牌即可选它当对手。默认关闭。独立服务器可在 `config/bosslandlord-server.toml` 设置 `challengeAnyMobInSurvival = true`。

## 打牌与结算

- 选角页可邀请同维度、32 格内的空闲玩家「同桌挑战 Boss」或「好友对决」。对着好友按 **F7** 可直接打开对决选人页。附近没有 Boss 时，**F7** 也会列出可邀请的玩家。对方在聊天点击「接受」后开局。
- 局域网或服务器上，房主附近有两位可入座的玩家时，可在好友页点「三人桌」并选择两位不同的好友。两人都在聊天点「接受」后，三位真人打友谊局。随机一席先叫，三人各有一次叫地主或抢地主的机会，最后叫牌者当地主。三人都不叫会重新发牌。有人中途离席或掉线会结束本局，其余好友可以右键牌桌观战。
- 好友对决由双方竞选地主，闹吃补第三席，双方都不叫就重新发牌。邀请前可选友谊局、生命或贵重物品。对方在聊天里能看到完整赌注，接受后才入座。生命局的输家扣除最大生命的三分之一。物品局双方各押一个同种物品，胜者拿走两份，背包满时会在腾出空间后发放。认输或断线按负局结算，因服务器关闭等原因取消的未决对局退回物品。
- 与好友同桌挑战生物时，好友固定为农民，赌注由房主与该生物结算。好友中途离席后由闹吃接手。
- 未入座的玩家可以右键牌桌观战，只能看到公开牌况。牌局进行时所有参赛者免受旁观玩家和敌对生物的伤害。结算后清除参赛玩家附近 10 格内的普通敌对生物，命名生物、Boss 和其他牌局的参与者保留。

- 点击或按住左键拖过牌面选牌。**Enter** 出牌，**空格** 不出，**H** 提示（重复按可换方案），右键清空选择。轮到玩家后默认有 45 秒，超时会自动代出合法牌。
- 玩家先看 17 张手牌，决定叫不叫地主。Boss 可以反抢，玩家可以最后再抢一次。第三席固定当农民。地主收三张底牌并先出，两名农民各 17 张。
- 洗牌时会按同一标准检查三家的起手牌，减少大牌集中在一席、或整手多对却组不出顺子的情况。每局最多试洗五次，保留首次洗牌中起手是否有人拿到四张炸弹的结果。选定整副牌后才开始竞选地主。
- 玩家当地主时，可选 **不加倍 ×1、加倍 ×2、超级加倍 ×3**，对应输家扣 **1/3、2/3、全部最大生命**。鼠标移到倍率按钮上可预览双方扣血量。Boss 当地主时，赌注为 ×1。玩家所在一方获胜就扣 Boss 血，反之扣玩家血。
- 支持单张、对子、三带、顺子、连对、飞机、四带二、炸弹和王炸。两人连续不出后，上一个出牌的人自由领牌。出牌会飞到桌面，飞机、炸弹、王炸和击落飞机各有动画。
- Boss 和牌友会用底牌、已出牌和公开余牌数估计对手能否跑牌。残局会抽取更多可能的牌型分布，并为每个候选走法分配独立的搜索额度。普通跟牌倾向用够压过对手的小牌，优先拦截可能一手出完的对手。
- 入座后打开底部「道具」，先点名字切换对象，再选鸡蛋、雪球、纸团或倒杯水。道具可以重复使用。同一玩家的所有道具合计连用 5 次后冷却 10 秒，连续 10 秒未使用也会清空连用次数。换对象或重开牌局不会跳过冷却。互动有飞行动画、粒子和音效，无伤害。
- **V / F5** 或右上角按钮切换第一人称与第三人称。第三人称从玩家身后看向两侧座位。**Esc** 收起界面，按 **F7** 或右键牌桌返回。「认输」需再点一次确认，也可用 `/bosslandlord leave`。主动离开服务器按认输处理。
- 牌局配乐来自小旭音乐的《欢乐斗地主配乐合集》。开桌后循环「游戏中」，任意牌手剩 5 张或更少时切换到「激烈」，结算时播放一次「胜利」或「失败」。每组随机选曲，音量随游戏的「音乐」滑块调整。
- 结果页可立即「结算离桌」或「再来一局」。输给 Boss 时，房主可用「掀桌重来」取消本局扣血、重新洗牌。好友对决或联机同桌的重赛会重新发送邀请。收桌后可立即发起下一局。

## 自测

1.5.1 用生图模型制作了选角页的铜色街机舞台、四张选人卡和按钮贴图。上方选择牌友，下方舞台显示实时 3D 模型。牌桌、牌面和结算恢复到 1.4.0 的样式。

闹吃保留黑礼帽、浓须和工装裤，古振兴保留短发、灰色束脚裤与赤足。角色包含呼吸待机、坐姿和出牌动画。自 1.5.2 起，两位角色入座后第一次轮到自己出牌或过牌时，会抬起双手、左右摇摆并播放自己的歌声。每局唱一次，音量由「友好生物」控制。

可编辑源文件在 `models/blockbench/naochi.bbmodel` 和 `models/blockbench/gu_zhenxing.bbmodel`，均在 Blockbench 的 GeckoLib Entity 格式中建模并导出。运行资源为 `geo/*.geo.json`、`animations/guest.animation.json` 和 `textures/entity/guest/*.png`。修改后使用 Blockbench 的 GeckoLib 导出功能；`tools/generate_guest_models.py` 只准备建模数据和纹理，不代替 Blockbench 导出。

GeckoLib 使用官方 [NeoForge 1.21.1 / 4.9.3 发行版](https://modrinth.com/mod/geckolib/version/Grwn5rUB)，Gradle 从官方 Modrinth Maven 拉取，JAR 不内嵌此依赖。首次构建需要联网。

可以在自己的测试存档里用 `/summon minecraft:warden`、`/summon minecraft:wither` 或 `/summon minecraft:ender_dragon` 召唤对手。建议先测一局监守者，观察三人入座、选牌提示、赢输扣血和收桌回原位，再换凋灵和末影龙看座位表现。无其他生物和有村民在旁时各开一次，能看到补位和邀请的区别。

使用 Java 21，Windows 下运行 `gradlew.bat build`，Linux 或 macOS 下运行 `./gradlew build`。构建后的模组位于 `build/libs/`。`logicTest` 离线检查竞选地主、牌型、整局流程和倍率扣血。
